# Professional Self-Assessment

Completing the Computer Science program at Southern New Hampshire University has helped me see how much I have grown both technically and professionally. When I began the program, many of my assignments were focused on learning individual programming concepts and getting a program to work correctly. As I progressed through the program, I began to understand that computer science involves much more than simply writing code. A good solution also needs to be organized, secure, efficient, understandable, and useful to the people who depend on it. Developing my ePortfolio has given me the opportunity to bring those skills together and show how my work has improved over time.

One of the areas where I have grown is working in collaborative environments. Even when a project is completed individually, software development is rarely isolated from other people. Developers need to communicate with instructors, team members, users, managers, and other stakeholders. Throughout my coursework, I learned the importance of explaining technical decisions clearly and listening to feedback. Code reviews, discussion assignments, project documentation, and testing all helped me think about how another person might understand or maintain my work. In my CS 499 code review, for example, I examined an existing application and explained its strengths, weaknesses, and planned improvements in a way that could be understood by another developer or manager. This helped me practice looking at software from both a technical and collaborative perspective.

My communication skills have also improved throughout the program. Computer science can involve complicated ideas, but those ideas are not useful if they cannot be explained clearly. I have learned to adjust the way I communicate depending on the audience. Some assignments required detailed technical explanations, while others required me to explain concepts in a way that someone without a computer science background could understand. This is important because stakeholders may care more about what a system accomplishes than the specific code behind it. Through written reports, diagrams, presentations, code comments, and project documentation, I have become more comfortable explaining what I created, why I made certain decisions, and how those decisions affect the user.

Data structures and algorithms have helped me become more thoughtful about how programs process information. Earlier in the program, I often focused mainly on whether a solution produced the correct result. Later courses taught me to also consider efficiency, organization, and design trade-offs. In my capstone, I applied these ideas by creating a rescue-candidate ranking system that uses dictionaries and a bounded priority queue to identify the strongest candidates without unnecessarily sorting every record. This enhancement helped me understand that choosing a data structure should be connected to the actual problem being solved. It also gave me practical experience analyzing time and space complexity instead of treating those concepts as only theoretical ideas.

Software engineering has been another major area of growth. I have learned that code that works is not always code that is easy to maintain. My earlier projects often placed a large amount of functionality together because my main goal was to make the program run. During the capstone, I revisited my Grazioso Salvare Rescue Candidate Dashboard and separated responsibilities into different modules for configuration, database access, services, interface layout, and callbacks. I also added automated testing and improved error handling. This made the application easier to understand, test, and expand. Other projects throughout my program also helped me become more comfortable working with different technologies and solving problems across several areas of computer science.

My database experience has taught me how important reliable data management is to a complete software solution. Working with MongoDB in the Grazioso Salvare project allowed me to go beyond simply retrieving records. I eventually added validation, indexing, aggregation, and more complete create, update, and delete functionality. The enhancement also required me to think about how database design affects performance and reliability. I learned that good database work includes not only storing information but also validating it, retrieving it efficiently, and protecting it from incorrect or unsafe changes.

Security has become increasingly important in the way I approach software development. Earlier in my program, I did not always think about security until it appeared as a specific requirement. Through cybersecurity coursework and the capstone, I learned that security should be considered throughout the development process. In the Grazioso Salvare application, I removed database credentials from the source code and stored them in environment variables instead. I also used input validation, safer error messages, and defensive programming techniques. These changes showed me that protecting data and limiting unnecessary exposure are responsibilities that should be considered from the beginning of a project rather than added at the end.

The ePortfolio also reflects how my professional goals have developed. I am interested in continuing to build my skills in software development and artificial intelligence, especially in roles where I can solve technical problems and continue learning. My coursework has shown me that I enjoy improving systems, working through technical challenges, and finding ways to make software more useful and reliable. Completing the Computer Science program has given me experience with programming, databases, networking, cybersecurity, full-stack development, algorithms, embedded systems, testing, and software design. Together, these areas have given me a broader understanding of how different parts of computer science connect.

The technical artifact in this portfolio brings many of these skills together. I selected the Grazioso Salvare Rescue Candidate Dashboard because it gave me a strong opportunity to demonstrate growth in several areas using the same application. The Software Design and Engineering enhancement improved the structure, maintainability, security, and usability of the program. The Algorithms and Data Structures enhancement added a scoring and ranking system that uses appropriate data structures to prioritize rescue candidates. The Database enhancement expanded the application with validation, indexing, aggregation, and more complete data-management capabilities. Using the same artifact across all three enhancement categories allowed me to show how one application can evolve when it is examined from different areas of computer science.

Overall, this ePortfolio represents more than a collection of completed assignments. It shows the progression of my skills throughout the Computer Science program and my ability to revisit earlier work with a stronger understanding of software development. I have learned how to analyze an existing solution, identify areas for improvement, make design decisions, test those decisions, consider security and performance, and explain my work clearly. These skills have helped prepare me to continue learning and contribute in a professional computer science environment.
