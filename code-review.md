## Grazioso Salvare Rescue Candidate Dashboard

For my CS 499 code review, I selected the Grazioso Salvare Rescue Candidate Dashboard that I originally created in CS 340: Advanced Programming Concepts. The application uses Python, MongoDB, Dash, Pandas, Plotly, and Dash Leaflet to provide an interactive way to review Austin Animal Center data and identify animals that may be suitable for search-and-rescue roles.

The purpose of my code review was to examine the original artifact before making my capstone enhancements. I reviewed the existing functionality, identified areas that could be improved, and explained my plans for enhancing the project in three areas: Software Design and Engineering, Algorithms and Data Structures, and Databases.

## Areas Identified During the Review

During the review, I found that the original application was functional but could be improved in several areas. Much of the database access, interface layout, filtering logic, visualization logic, and callbacks were located together in one notebook. This made the project harder to maintain, test, and expand.

I also identified opportunities to improve security, input validation, error handling, code organization, database operations, and the way rescue candidates were evaluated. These findings became the foundation for the three enhancements completed later in the capstone.
